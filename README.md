## ✅ Completed Tasks

### 🧊 Task 1 - Temperature Conversion Tool (C++)

A C++ console-based tool that converts temperature between **Celsius**, **Fahrenheit**, and **Kelvin**. The user inputs a temperature value and selects the source and target scales.

- Supports all 6 conversion combinations
- Uses modular functions for cleaner logic
- Outputs formatted results with two decimal precision

### 🎮 Task 2 - Number Guessing Game (C++)

A fun console-based game where the program randomly selects a number between 1 and 100, and the user tries to guess it.

- Implements random number generation (`rand()`, `srand()`)
- Provides real-time feedback (“Too high” / “Too low”)
- Ends when the correct number is guessed

### 🧩 Task 3 - Sudoku Solver (C++)

A powerful Sudoku solver built with a **recursive backtracking algorithm**. Users enter a 9x9 grid with empty cells as `0`, and the program solves the puzzle.

- Checks row, column, and 3x3 grid constraints
- Uses recursion and backtracking for solution finding
- Informs the user if no solution exists

### 🛒 Task 4 - Snapdeal Web Scraper (Python)

A Python script that scrapes data from **Snapdeal** for the search term "mobile". It collects product names, prices, and ratings for the top 5 results and saves them into a CSV file.

- Uses `requests` and `BeautifulSoup` for web scraping
- Data stored using `pandas` into `snapdeal_products.csv`
- My first web scraping project, inspired by **CodeWithHarry's** YouTube tutorial
